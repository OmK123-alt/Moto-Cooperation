# Moto Cooperation 3D Landing

This is an optional React/Vite landing page. The existing `frontend/` site files are untouched.

## Required Assets

Drop production assets here:

- `public/models/car.glb`
- `public/hdri/studio.hdr`

The vehicle can be replaced later by changing only `public/models/car.glb`.

## Run

```bash
npm install
npm run dev
```
